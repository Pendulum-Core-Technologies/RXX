# How do I use it?
You need an executor. Preferably Volt, Potassium, Real or for mobile: Delta and Codex.
Execute Compiler.lua.
You will notice a file called "game.raw" in your exploit's Workspace folder. That is the data compiled from the game.
When you're gonna clone new games, you *must* delete your previous game.raw file before doing so.
Disclaimer: *heavier* games may crash your Roblox client. This issue may be solved in the future.

# How do I load it?
Go into Studio.
Execute Loader.lua.
Wait for everything to load.
Done.
