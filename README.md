# How do I use it?
You need an executor. Preferably Volt, Potassium, Real or for mobile: Delta and Codex.</p>
Execute Compiler.lua.</p>
You will notice a file called "game.raw" in your exploit's Workspace folder. That is the data compiled from the game.</p>
When you're gonna clone new games, you *must* delete your previous game.raw file before doing so.</p>
